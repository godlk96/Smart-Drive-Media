# 行车记录6视角剪辑 - 按钮功能说明文档

## 项目概述
本项目是一个行车记录6视角视频剪辑工具，包含首页（index.html）和编辑页（edit.html）两个主要页面。

---

## 一、index.html 按钮功能说明

### 1. 多选按钮

#### 作用
- 点击后进入多选模式，允许用户选择多个视频组进行合并剪辑
- 再次点击则退出多选模式

#### 点击后的限制
- 进入多选模式后，点击视频组卡片不再进入单个编辑页面，而是切换选中/未选中状态
- 退出多选模式时，会清空所有已选择的视频组

#### 触发的功能
1. **进入多选模式**
   - 按钮文字从"多选"变为"取消"
   - 按钮添加橙色背景（.active 样式）
   - 边框同时变为橙色

2. **选择视频组**
   - 视频组卡片添加橙色边框（.selected 样式）
   - 卡片右上角显示橙色圆形勾选标记（✓）
   - 已选择的视频组ID会被添加到 selectedGroups 集合中

3. **取消选择视频组**
   - 移除视频组卡片的橙色边框
   - 隐藏右上角的勾选标记
   - 从 selectedGroups 集合中移除该视频组ID

4. **显示/隐藏合并剪辑按钮**
   - 每次选择或取消选择时都会检查 selectedGroups 的大小
   - 当已选择视频组数量 ≥ 2 时，显示"合并剪辑"按钮
   - 当已选择视频组数量 < 2 时，隐藏"合并剪辑"按钮

5. **退出多选模式**
   - 点击"取消"按钮
   - 按钮文字恢复为"多选"
   - 移除橙色背景样式
   - 清空所有已选择的视频组（selectedGroups.clear()）
   - 重新渲染视频组列表，移除所有选中样式

---

### 2. 合并剪辑按钮

#### 作用
- 将用户选择的多个视频组合并后跳转到编辑页面进行剪辑

#### 限制
- 必须在多选模式下且已选择至少2个视频组时才会显示
- 未选择任何视频组时点击无反应

#### 触发的功能
- 将所有已选择的视频组ID转换为逗号分隔的字符串
- 跳转到 edit.html，并通过 URL 参数传递以下信息：
  - `type=merge`：表示是合并剪辑模式
  - `groupIds=1,2,3`：已选择的视频组ID列表

---

## 二、edit.html 按钮功能说明

### 1. 返回按钮

#### 作用
- 从编辑页面返回到首页（index.html）

#### 限制
- 如果用户有未保存的修改，点击返回时会显示确认对话框
- 只有在用户确认放弃修改后才会返回首页

#### 触发的功能
1. **检查是否有未保存修改**
   - 检查 `hasUnsavedChanges` 标志
   - 如果为 false（无未保存修改），直接跳转到 index.html

2. **显示确认对话框**
   - 如果有未保存修改，显示模态框
   - 模态框标题："确认放弃修改？"
   - 提示内容："返回将丢失未保存的修改"
   - 两个按钮：
     - "继续编辑"：关闭对话框，留在当前页面继续编辑
     - "放弃"：跳转到 index.html，放弃所有修改

---

### 2. 导出剪辑按钮

#### 作用
- 将当前编辑页面的所有状态参数传递到 export.html 页面进行导出

#### 限制
- 无明确限制，随时可以点击导出

#### 触发的功能
- 收集当前页面的所有状态参数，通过 URL 传递给 export.html
- 传递的参数包括：
  - `type`：剪辑类型（single 或 merge）
  - `groupId`：单个视频组ID（仅单剪辑模式）
  - `groupIds`：多个视频组ID列表（仅合并剪辑模式）
  - `template`：当前选中的模板ID
  - `templateName`：模板名称
  - `resolution`：模板分辨率
  - `speed`：当前播放速度
  - `mosaicEnabled`：打码开关状态（true/false）
  - `clipMarks`：剪辑点数组（JSON 格式）
  - `selectedViews`：已选择的视角（JSON 格式）
- 跳转到 export.html 页面

---

### 3. 播放按钮

#### 作用
- 控制视频播放和暂停的切换
- 播放时播放头自动前进

#### 限制
- 无明确限制

#### 触发的功能
1. **切换播放/暂停状态**
   - 点击时切换 `isPlaying` 标志
   - 按钮图标在播放（▶）和暂停（⏸）之间切换

2. **播放时**
   - 状态标签显示"播放中..."
   - 启动定时器，每100毫秒更新一次播放头位置
   - 播放头位置 = 当前时间 + 0.1秒 × 播放速度
   - 当播放到总时长结束时，自动回到开头循环播放

3. **暂停时**
   - 状态标签显示"已暂停"
   - 停止定时器，播放头停止在当前位置

---

### 4. + 按钮（添加剪辑点）

#### 作用
- 在当前播放头位置添加一个剪辑点

#### 限制
- 最多只能添加2个剪辑点
- 当已添加2个剪辑点时，点击会提示"最多只能添加2个剪辑点"

#### 触发的功能
1. **检查剪辑点数量**
   - 如果 `clipMarks.length >= 2`，显示提示信息并返回

2. **添加剪辑点**
   - 将当前播放时间 `currentTime` 添加到 `clipMarks` 数组
   - 标记 `hasUnsavedChanges = true`（有未保存修改）
   - 重新渲染剪辑点和剪辑区域
   - 显示提示："已添加剪辑点"

3. **剪辑点显示**
   - 在时间轴上显示橙色竖线标记
   - 竖线顶部有橙色小三角指示
   - 当有2个剪辑点时，两点之间会显示半透明橙色区域表示剪辑片段

---

### 5. ✕ 按钮（撤回剪辑点）

#### 作用
- 撤回上次添加的剪辑点

#### 限制
- 没有剪辑点时点击会提示"没有可撤回的剪辑点"

#### 触发的功能
1. **检查是否有剪辑点**
   - 如果 `clipMarks.length === 0`，显示提示信息并返回

2. **撤回剪辑点**
   - 从 `clipMarks` 数组中移除最后一个元素（pop）
   - 标记 `hasUnsavedChanges = true`
   - 重新渲染剪辑点和剪辑区域
   - 显示提示："已撤回上次剪辑点"

---

### 6. 模板按钮

#### 作用
- 选择不同的剪辑模板，改变预览布局

#### 限制
- 模板按钮可能会因为缺少必要的视角而被禁用
- 禁用的按钮显示半透明状态，鼠标悬停时显示"缺少X视角，无法使用该模板"
- 点击禁用的模板按钮无反应

#### 触发的功能
1. **模板列表**
   - 共5个预设模板：
     - 单视角（1920×1080）
     - 防追尾双录（1920×2160）
     - 避险防加塞（1920×1620）
     - 左右盲区（3840×1080）
     - 沉浸式旅拍（3840×1080）

2. **选择模板**
   - 点击可用的模板按钮
   - 该模板按钮变为橙色背景和边框（.active 样式）
   - 标记 `hasUnsavedChanges = true`
   - 改变预览区域的宽高比（paddingTop）

3. **功能联动**
   - 根据模板是否支持打码，显示或隐藏"前视角固定打码"开关
   - 根据模板是否支持音频，显示或隐藏"全局静音"标签
   - 更新预览布局，显示对应数量和排列的视角窗口

---

### 7. 打码开关

#### 作用
- 控制前视角固定打码的显示或隐藏

#### 限制
- 仅在支持打码的模板下可见
- 模板不支持打码时，该开关会被隐藏

#### 触发的功能
1. **开关切换**
   - 点击开关时切换 `mosaicEnabled` 状态
   - 开关打开时，滑块移到右侧，背景变为橙色
   - 开关关闭时，滑块移到左侧，背景变为灰色

2. **预览更新**
   - 标记 `hasUnsavedChanges = true`
   - 更新预览区域
   - 前视角窗口中显示或隐藏黑色半透明打码框（位于底部中央位置）

---

### 8. 倍速选择

#### 作用
- 选择视频播放速度

#### 限制
- 只能选择预设的4种速度：0.5x、1.0x、1.5x、2.0x
- 默认选择1.0x

#### 触发的功能
1. **选择速度**
   - 从下拉菜单中选择一个速度选项
   - 更新 `currentSpeed` 变量

2. **显示更新**
   - 标记 `hasUnsavedChanges = true`
   - 更新预览区域右上角的速度徽章，显示当前选择的速度（如"1.5x"）

3. **播放影响**
   - 如果正在播放，播放速度会立即生效
   - 播放头前进的速度 = 0.1秒 × 选择的倍数（每100毫秒更新一次）

---

## 三、其他功能说明

### 时间轴点击跳转
- 点击时间轴的任意位置，播放头会跳转到对应位置
- 可以拖动播放头到任意位置

### 剪辑区域显示
- 当有2个剪辑点时，两点之间会显示半透明橙色区域
- 该区域表示选中的剪辑片段

### 提示信息（Toast）
- 操作成功或失败时，屏幕底部会显示2秒的提示信息
- 例如："已添加剪辑点"、"最多只能添加2个剪辑点"等

---

## 四、数据传递流程

### index.html → edit.html
- 单剪辑：`edit.html?type=single&groupId=1`
- 合并剪辑：`edit.html?type=merge&groupIds=1,2,3`

### edit.html → export.html
- 传递所有编辑状态参数到导出页面
