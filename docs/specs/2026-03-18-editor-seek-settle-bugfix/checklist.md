# 验收检查清单（Checklist）

## 用户体验
- [ ] 拖拽松手后仅发生一次落点
- [ ] 不出现“横跳两次”或回弹到旧位置
- [ ] 拖拽末尾与时间文本一致

## 调度稳定性
- [ ] 拖拽 update 不触发真实 seek commit
- [ ] 拖拽 end 仅触发一次最终 seek
- [ ] settling 窗口内旧回调不会覆盖最终落点
- [ ] 仅最新 seek 回调可更新全局游标

## 日志与性能
- [ ] 拖拽期间 `拖动全局进度` 日志显著减少
- [ ] seek 请求次数与拖拽 update 次数解耦
- [ ] 无异常请求堆积告警

## 工程质量
- [ ] hvigor 构建通过
- [ ] ArkTS 无新增 ERROR
- [ ] 自动化测试通过
