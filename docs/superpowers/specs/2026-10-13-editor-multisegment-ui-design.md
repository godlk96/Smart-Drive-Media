## 1. 目标

1. 剪辑页从「单区间」升级为「多片段」，每段独立设置**倍速**和**声音**。
2. 整页重做：现在这一版用户明确说「low」，具体两处 —— **进度条**和**预览区**。
3. 顺带解决三个现存问题：三个强调色互相打架、没有主题文件（颜色全部硬编码在页面里）、预览比例写死与模板打架。

## 2. 非目标

- 不动首页（`pages/Index.ets`）与行程库。
- 不动模板定义本身（`model/Models.ets` 的 5 个模板保持原样）。
- 不做水印开关的 UI（`watermarkEnabled` 字段保留，不在本页出现）。
- 不做撤销/重做栈的重新设计（沿用现有 `undoClipMark` 的语义，见 §5.7）。

## 4. 设计方向与决策

### 4.1 方向选择（brainstorm 过程）

1. 首轮两案：**A 专业监看台**（强调 `#38BDF8`）vs **B 黑金极简**（iOS 相册式，强调 `#FFD60A`）→ 选 A。
2. 但 A/B 只换了颜色，骨架一样 → 重出三案 **C 画面优先 / D 片段优先 / E 机位优先** → **选 D**。理由：代码里真实交互就是「+ 加一个剪辑点 / ✕ 撤销」，用户是在拼片段，不是在拉一条精确时间轴。
3. 配色：深色界面里外壳与画面同为黑 → 「所有东西一样重、没有主角」。改浅色外壳后整屏只剩画面一块深色，层级不用画线就成立。三套浅色里 **选 P1 纸白**。
4. 结构最终形态：**播放器面板** —— 时间轴钉在画面正下方、同一张卡里，不再单独成区。理由：片段与时间轴是同一件事，分成两块就是「画两遍」；且 T3/T4 预览 32:9 在手机上只有约 74px 高，浮动拖动条会吃掉大半画面并撞系统手势。

### 4.2 关键决策

| # | 决策 | 理由 |
|---|---|---|
| D1 | 整条视频本身就是一个片段，默认一整段覆盖全片 | 零操作即可导出全片；「剪」是减法，先有一整段再切掉不要的；划光所有段就回到它，不存在「没东西可导出」 |
| D2 | 剪刀在播放头位置落刀 | 用户明确要求「在视频里加一个剪刀图标」 |
| D3 | 进度条放在**画面区内部**（底部浮层） | 用户：「不显示在片段哪个区域，就显示在播放器的区域，和其他的视频软件一样」 |
| D4 | 进度条两端显示时间（左＝当前位置，右＝片长） | 最小段长 2 秒，落刀要卡时间，完全没有时间参照会很难对；贴在线两端不额外占行、不压画面 |
| D5 | 播放键在画面**正中**，播放时淡出 | 用户明确要求；也是现有行为（56×56 覆盖层） |
| D6 | 倍速单按钮循环，五档 `0.75x → 1.0x → 1.25x → 1.5x → 2.0x` | 用户要求「通过多次点击来切换而不是多个按钮」；钳位本来就是 0.75–2.0，底层不用动 |
| D7 | 声音按钮**两态**（原声 / 静音），纯图标无边框无文字 | 用户：「音量 要不就没有，要不就原声」→ 保留 `muted: boolean`，导出契约不用动 |
| D8 | 段数上限 **3 段**，最小段长 **2 秒** | 用户指定 |
| D9 | 参数行在轨道**上方**，只显示选中段自己的时长 | 用户：「第一个片段 0:00 到 0:15，选中上方显示 15S 就可以，不用显示具体时间从哪到哪」 |
| D10 | 段块只写时长，不写编号 | 用户：「1 2 3 的文案也可以不要了，就显示 15S 30S 这写」 |
| D11 | 选中段只换边框（1.5px 琥珀）+ 两端竖向胶囊手柄，**不铺底色** | 用户：「选中的片段观感太重了，不美观」 |
| D12 | ~~段间留 3px 缝 + 每段独立圆角块~~ **⚠️ 2026-10-15 作废：改为段间不留缝** | 原理由（用户：「区分不出来有几个剪辑片段」）在真机上被证伪：那道缝反过来让人以为「中间丢了一部分画面」。现在轨道上每一寸宽度都必须对应真实时间——没有空档项就没有缝；段块圆角同时收小，免得接缝上下凹出四分之一圆又成一道假缝。真正的空档仍按真实时长占宽，它才是「这里没有内容」的唯一表示。 |
| D13 | `✕` = 这一段不要了（变灰划掉、导出跳过、可恢复） | 用户：「X 是这一段不要了」 |
| D14 | ~~播放**跳过灰段**~~ **⚠️ 2026-10-15 作废：预览播整条源视频，不按片段跳过** | 用户：「期望进度条可以播放整个视频，不受片段影响」。旧理由（成片不含灰段）只对导出成立：导出由 `toExportSegments` 只取启用段决定，跟预览的播放范围无关。页面按 `playbackSkipTargetSec` 跳段时，末段之后的片尾空档其跳过目标正好是 `totalDurationSec` —— 一播到最后一个片段的结束位置，进度条就冲到视频末尾。`playbackSkipTargetSec` 已删除。 |
| D15 | 导出按钮只写「导出」两字 | 用户指定 |
| D16 | 导出浮层**不加成片时长**，保持原来的转圈 + 文字 | 用户：「那就不显示成片55秒了，直接就原来的进度」 |
| D17 | 改过的段（倍速≠1.0 或静音）**不挂标记** | 用户：「暂时不需要标记」 |
| D18 | 画面上不显示模板名、时间水印、机位计数等文案 | 用户：「视频区域不需要显示 避险防夹塞这些文案 还有时间」「不需要显示有几段成片 源片，这些数据有些无意义」 |

## 5. 交互规格

### 5.1 顶栏

- 左：返回箭头（`19`，`#57534A`）。未保存时弹「确认放弃修改？」（沿用现有 `handleBack()` / `backConfirmVisible`）。
- 中：片名，单行省略。
- 右：`导出` 按钮（`#111111` 底、白字）。**不带时长**。

### 5.2 画面区

- 比例跟随模板：`EditorViewModel.getPreviewAspectRatio(templateId)`。T1 8:9 / T2 32:27（默认）/ T3·T4 32:9 / T5 16:9。
- 分区布局由 `EditorPreviewArea` 的 `buildSlotGeometry` 决定（3 个常驻槽位 slot_0/1/2，切模板只改 controller 的机位与段，槽位身份不变）。
- **居中播放键**：56，玻璃底，点击播放/暂停；播放中淡出，点击画面重新出现。
- **底部浮层**（高 84，底部渐变到透明）：
  - 进度条行（高 20）：线（高 2，`rgba(255,255,255,.30)`）+ 圆钮（14，白）。
  - 两端时间（11，`rgba(255,255,255,.84)`，等宽数字）：左＝当前位置，右＝源片总时长。
  - 控制行（高 28）：左空，右剪刀圆钮（28）。
  - 拖动圆钮时，圆钮上方浮一个时间气泡，松手消失。

### 5.3 落刀规则（剪刀）

统一规则：**在 p 落刀 → p 到「下一个边界」之间成为「要的」，p 之前保持原状。**

| 落刀位置 | 结果 |
|---|---|
| 活段 `[a,b]` 内 | 切成 `[a,p]` + `[p,b]`，两段都是活段，成片时长不变 |
| 灰段 `[a,b]` 内 | `[p,b]` 恢复成活段，`[a,p]` 仍是灰段 |
| 最后一段之后 | 新增 `[p, 片尾]` |

例（用户给的）：已有 `0:00–0:15` 和 `0:30–0:59`，在 `0:20` 落刀 → 新增 `0:20–0:30`，`0:15–0:20` 仍是灰段。

### 5.4 选中与联动

- 点片段块 → 该段选中，进度条圆钮**跳到该段起点**。
- 拖进度条圆钮 → 圆钮落在哪一段，那一段选中；落在灰段则没有选中段（参数行只显示段名与时长，倍速/声音按钮置灰或隐藏 —— 实现时择一，建议隐藏）。
- 播放时圆钮跟着走，**覆盖整条源视频**（0 → 总时长连续推进，空档与灰段照常播）。「跳过灰段」只在导出结果里体现（`toExportSegments` 只取启用段）。

### 5.5 段数 / 段长限制

- 最多 3 段。达到上限时剪刀置灰，点击提示。
- 最小段长 2 秒。落刀后任一段短于 2 秒则拒绝并提示。

### 5.6 每段参数

- 参数行在轨道上方，内容：`片段 N` · 时长 · 倍速胶囊 · 声音图标 · `✕`。
- **倍速**：点击循环 `0.75x → 1.0x → 1.25x → 1.5x → 2.0x → 0.75x`，显示小写 x。
- **声音**：点击在 原声 / 静音 之间切换，图标随状态变（有弧线 / 加斜线），**无边框无文字**。
- 默认值（1.0x 且原声）不做任何视觉强调。

### 5.7 `✕` 与撤销

- `✕` = 这一段不要了：段留在轨道原位、变灰、加删除线，导出时跳过。
- 只剩一段时，那一段就是整条视频本身，`✕` 不再生效。
- 现有 `undoClipMark()`（`pages/Editor.ets:289-304`）的「撤销最后一个剪辑点」语义保留为返回箭头路径上的一部分；本页不再有独立的撤销按钮。

### 5.8 模板行

- 横向滚动，5 个模板（`model/Models.ets`）。
- 缺机位的模板整卡 40% 不透明、不可点（现有 `isTemplateDisabled` + toast「缺少X视角，无法使用该模板」保留）。

### 5.9 导出

- 点「导出」→ 现有流程（`ExportService` → `CoreBridge` → native）。
- 浮层：全屏遮罩 `#88000000` + 居中列（转圈 54 + 文字 `正在导出…`）。**不显示成片时长。**

## 8. 验收标准

1. 进页面默认是一整段覆盖全片；不剪任何一刀就能调倍速/声音并导出。
2. 点剪刀能切出第 2、3 段；到 3 段时剪刀不可用并有提示。
3. 任一段短于 2 秒时落刀被拒绝并有提示。
4. 点片段块 → 该段选中且进度条圆钮跳到该段起点。
5. 每段的倍速与声音互不影响；改一段不动其他段。
6. `✕` 后该段变灰划掉，导出结果里不含它；**预览播放仍会播到它**（进度条覆盖整条视频，不按片段跳段）。
7. 倍速按钮点击顺序为 `0.75x → 1.0x → 1.25x → 1.5x → 2.0x → 0.75x`。
8. 声音按钮点击在 原声 / 静音 之间切，图标随之变化。
9. 画面比例跟随模板切换（T1 8:9、T2 32:27、T3/T4 32:9、T5 16:9）都正确。
10. 导出浮层只有转圈 + 文字，无成片时长。
11. 全页无 `#FF7A00` / `#0A59F7` / `#FF4444` 残留。
